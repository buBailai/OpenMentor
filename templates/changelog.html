OpenMentor 各版本面向老师的功能更新

v1.3.0 2026-05-23

移动控制台 + 数据使用矩阵 + 视频演示体系

  • 移动控制台：AI 导师列表新增「移动控制台」入口和二维码，老师可以用手机或平板打开轻量控制台，在课堂中快速查看并管理自己的全部 AI 导师。
  • 课堂应急控制：移动端支持切换图片输入、文件上传、图片生成等常用开关；支持维护黑名单分类与关键词、查看黑名单命中记录、禁用 / 解禁学生身份，以及一键熔断或重新启用某个 AI 导师。
  • 学生链接移动端管理：移动控制台中可查看学生访问链接和二维码，支持复制、投屏或转发；学生链接过期后，也可以在移动端直接重置有效时长。
  • 数据使用矩阵：数据任务详情页将原「数据提交说明」升级为卡片式「数据使用矩阵」，按「数据采集」和「数据分析」组织常用场景，页面不再直接铺开大段提示词。
  • 5 个数据任务使用场景：矩阵内置「基础提交页面」「附件采集功能」「AI 导师悬浮球功能」「基础数据大屏」「本地附件查看功能」5 张场景卡片，每张卡片都提供「查看 / 复制 / 演示」按钮。
  • 数据大屏提示词模板：新增「基础数据大屏」提示词，引导老师先提交 1-2 条测试数据，再复制数据接口返回的完整 JSON 样例，让 AI 更容易按真实字段制作实时数据大屏。
  • AI 导师悬浮球提示词：新增可复制提示词，用于让 AI 在生成 HTML 数据采集页面时，把某个 AI 导师做成页面右下角悬浮球，学生填表时可以在小窗中同步向导师提问。
  • 提示词视频演示：数据使用矩阵的 5 个场景均已接入 B 站浮窗播放器，老师可以先看演示视频，再一键复制提示词照做。
  • 模型配置视频演示：设置页为 DeepSeek、豆包、阿里云百炼、智谱清言、硅基流动增加 API 申请 / 模型 ID 获取视频演示，帮助老师按当前官方页面找到正确配置项。
  • 模型配置说明优化：不再依赖容易过时的推荐模型文案，改为提示老师以官方平台当前模型 ID 为准，并通过视频演示学习查找方式。
  • 推荐他人使用入口：顶部导航新增推荐按钮，点击后打开 openmentor.top，并自动复制网址到剪贴板，方便老师直接分享给同事。
  • OpenMentor Skill 入口：页脚新增 OpenMentor Skill 链接，方便需要 AI Agent 辅助部署、配置和使用的老师查看配套 Skill。
  • 复制与配置稳定性优化：提示词复制增加剪贴板 API 与传统复制兜底；保存某个模型配置时，也会尽量保留其他模型已有配置。
  • 数据安全保护：启动时增加运行数据保护检查；如果数据库缺失但上传文件或报告目录中已有数据，会停止启动并提示检查数据库，避免静默创建空库造成误解。
v1.2.2 2026-05-15

修复版本号自动跟随的 bug

  • 修复：v1.2.1 加的「页脚版本号自动跟随 CHANGELOG」原本不生效（启动时缓存了常量），现已改为**按 CHANGELOG.md 修改时间缓存的动态读取**——改 CHANGELOG 后下次请求即生效，无需重启服务

  • 新增 2 行「参考提示词」复制按钮（数据任务详情页）：
    • · 带附件提交版：让 AI 一次写对带文件上传的 HTML 表单
    • · 打开服务器本地文件夹版：让数据大屏加「📁 打开服务器文件夹」按钮
  • 页脚版本号自动跟随 CHANGELOG，再也不用扫所有页面改硬编码版本
v1.2.0 2026-05-14

导师生态化 + 提示词智能优化 + 公式渲染

  • AI 导师广场：浏览全国老师分享的 AI 导师卡片，按学科 / 学段 / 关键词筛选，一键克隆到自己的库直接用
  • 分享自己的导师到广场：导师详情页一键发布，让好的提示词被更多老师受益（公开 + 不可撤回，已加二次确认）
  • AI 优化已有提示词：在编辑导师时，告诉 AI 你想怎么改（更适合小学生 / 增加互动性 / 缩短篇幅 等），AI 在保留原意基础上精准优化
  • 数学 / 化学公式渲染：所有 AI 回复 / 学情报告 / 智能分析自动识别 LaTeX (`$x^2$` / `$$\int$$`) 和 mhchem 化学式 (`\ce{H2SO4}`)，由本地 KaTeX 排版
  • 首页打卡 + 意见入口：「📍 打卡与意见」按钮 + 中国地图实时打卡热力图，「💬 提意见」跳飞书反馈
  • 更新日志页：右上角用户菜单加入口，老师能直观看到每版改了啥
  • 多处 UI 一致性修复：首页 hero 三按钮单行布局、各功能页标题字体统一

v1.1.3 2026-05-08

流式报告 + 文档预览 + 体验打磨

  • AI 学情报告 SSE 流式生成：单学生 / 全班级一键生成结构化报告，AI 边写边显示，自动持久化到「报告历史」可回看 / 下载 / 删除

v1.1.2 2026-05-07

AI 学情报告 + 多模态附件采集

  • AI 学情报告（首版）：基于学生对话历史和黑名单命中记录，AI 生成结构化分析报告
  • QuickForm 任务支持多模态附件上传：原本仅采集 JSON 文本，现在 multipart 表单可附图片 / PDF / Word / Excel / 音视频
  • 附件按日期分桶存储：所有附件按 `<日期>/<会话>/` 二级目录组织，长期使用不会单层目录爆掉
  • 服务器本机打开附件文件夹：审计页一键 reveal in Finder / Explorer，自部署场景免下载

v1.0 2026-05-06

第一个完整可用版本（内部）

  • AI 导师 CRUD：创建 / 编辑 / 删除 AI 导师，每个独立配置 system prompt、欢迎语、模型、多模态开关
  • AI 帮你写提示词：填几个问题或上传素材，AI 自动生成专业 system prompt 草稿
  • 学生扫码 / 链接即用：填班级 + 姓名身份验证后，SSE 流式 AI 回复，支持图片 / 文档输入 / AI 生图
  • 实时审计大屏：老师后台实时看每个学生的对话流，含图片 / 文件 / AI 生成图，每 5-8 秒自动刷新
  • 学情大屏：基于 ECharts 的 7 张图（每日趋势 / 班级活跃度 / 学生参与排行 / 满意度 / 24 小时热度等）
  • 班级花名册：Excel 导入或自由填写模式班级选项配置，年级 / 班级两层下拉
  • 对话评分：学生可对每条 AI 回复点 👍/👎，老师后台看满意度统计
  • 多重安全防护：每日消息上限 / 链接有效期 / 关键词黑名单（暴力·色情·越狱·作弊）/ 越狱检测 / 紧急熔断
  • 6 大国产 LLM 任选：DeepSeek / 豆包 / 通义 / 智谱 / 硅基流动 / Ollama 本地，全部 BYO API Key
  • 模板分享：一键导出 JSON 模板，老师之间互相导入克隆
  • 设备 × 身份双重隔离：token = sha256(device_uuid + class + name)，同名不同设备相互不可见
  • 本地化部署 + 数据隔离：所有数据存教师本地 SQLite，不上传任何第三方（除调用 LLM API）

还有更早的内部迭代（v0.x）但未公开发布，从 v1.1.1 起接受社区使用。
